## ▶️ Cómo abrir un proyecto

Cada carpeta es un proyecto de Android Studio independiente:

1. Clona el repositorio.
2. En Android Studio, selecciona **Open** y elige la carpeta del ejercicio, no la raíz del repositorio.
3. Espera a que Gradle sincronice y ejecuta con ▶️**Run**.

**Requisitos:** Android Studio (versión reciente) y JDK 21
